# SuperLabel — 视频抽帧标注平台

基于 **Flask + SQLite** 的轻量级视频帧标注平台，围绕
**建任务 → 抽帧 → 预标注 → 人工复核 → 发布导出** 的完整数据闭环设计，
支持多人多角色协作，前端零构建依赖（每页独立 html + js），部署即用。

---

## ✨ 功能总览

| 模块 | 说明 |
|------|------|
| 总览 | 全局统计大屏 |
| 原始视频管理 | 上传 / 预览 / 删除 |
| 任务广场 | 标注任务的创建与管理 |
| 数据集广场 | 抽帧后的数据集与发布 |
| 图库 | 帧图浏览与复核 |
| 后台管理 | 用户与角色管理 |

## 🧩 功能模块详细介绍

### 1. 总览（Overview）

登录后首页，汇总平台核心数据：任务数、数据集数、帧池规模、
标注/复核进度等，用于快速掌握整体产能与瓶颈。

### 2. 原始视频管理

- **多文件上传**：支持拖拽批量上传，自动提取时长/分辨率等元信息；
- **播放器预览**：上传后可直接在页面内播放确认内容；
- **删除保护**：删除视频仅移除平台记录及其派生帧，原始文件可另行处理；
- 视频是抽帧的源头：任务中添加视频后按参数抽帧进入任务帧池。

### 3. 任务广场（标注任务）

- **新建任务**：多选视频一次建单，双击任务名可直接改名；
- **任务详情页**（核心工作区），三栏布局：
  - **左栏**：任务视频列表 / 任务图像列表双视图切换
    - 视频缩略图竖列、hover 删除（删除该视频全部帧）、＋添加防重复；
    - 图像列表带标注状态色点（绿=已复核 / 黄=已自动标注 / 灰=未标注）；
    - 全选、删除所选、**定位**（一键跳到第一个未复核帧）；
    - "选择到这里"支持范围勾选；
  - **中栏**：帧池大图 + 底部横向帧列表
    - 帧列表懒加载、滚轮横滚、状态角标（黄绿灰）、hover 删帧；
    - 缩略图布局：左上状态点、右上删除、右下复选框（hover/选中时显示）；
  - **右栏**：可折叠卡片
    - **任务编辑**：标签集管理（一行一个、序号、颜色选择器、txt 批量导入自动配色）、置信度阈值、最大帧数；
    - **操作区**：抽帧（多选视频依次执行 + 进度条 + 停止）、自动标注（SAM2/VLM 预标注）、人工复核、查看即复核；
    - **导出与发布**：一键发布数据集（YOLO 格式）、导出地址、目录浏览器；
    - **标注详情**：当前帧的标签与坐标列表；
- **批量操作**：勾选帧批量删除（确认弹窗 + 数量提示）、按全局帧号安全删除，过滤视图下索引不出错。

### 4. 标注编辑器（中栏大图）

- **三种工具**：
  - **移动**：选择 / 拖动 / 8 向缩放手柄（边+角）；
  - **四边形**：两次点击画矩形，自动规范化；
  - **多边形**：逐点绘制，点起点或双击闭合；
- **标签交互**：框按标签颜色渲染并显示标签名；移动模式下右键标签弹出
  **带搜索框的标签列表**——自动聚焦、输入序号实时过滤、**Enter 快速选中**（见快捷键）；
- **防误触设计**：
  - 空格 / Ctrl 临时移动期间，画了一半的四边形/多边形会**挂起**，松开后**原样恢复**；
  - 右键菜单仅在移动模式生效，不影响绘制；
  - 保存失败时保留修改状态可重试，不丢标注；
- **自动保存**：修改后 600ms 防抖自动保存；人工保存即视为已复核。

### 5. 数据集广场 与 发布

- 抽帧产物以数据集形式管理，可跨任务浏览；
- **发布**：一键发布为 YOLO 格式数据集（images + labels + classes.txt），
  生成导出地址，内置目录浏览器直接取用。

### 6. 图库（Gallery）

- 全平台帧图浏览、按状态筛选、查看大图与标注；
- 支持"查看即复核"：浏览确认后自动计入复核进度。

### 7. 用户与权限

- **三角色**：`admin`（管理员）/ `lead`（组长）/ `annotator`（标注员）；
- Token 认证（密码仅存哈希），后台可增删用户、改角色、重置密码、停用；
- 审计：关键操作写入操作日志，任务页实时轮询展示。

### 8. 预标注引擎（扩展点）

- 预留 SAM2 / VLM 批量预标注接口：设定锚点帧后向前后传播，
  支持多实例、置信度阈值过滤；
- VM 无 GPU 时可对接 Windows GPU 节点，平台侧无感。

## ⌨️ 快捷键（标注编辑器）

### 临时移动（最常用）

| 按键 | 行为 |
|------|------|
| **按住 `Space`** | 临时切换到"移动"模式（工具栏高亮跟随、抓手光标），松开切回原工具 |
| **按住 `Ctrl`（单独）** | 同上；可与空格任选习惯使用 |
| `Ctrl` + 其他键 | 组合键不触发临时移动，快捷键正常（如 Ctrl+S） |

> 临时移动期间绘制到一半的四边形/多边形会被挂起，松开按键原样恢复，不丢进度。

### 标注操作

| 按键 | 行为 |
|------|------|
| `Esc` | 绘制中：取消本次绘制（起点/顶点）；否则：取消选中 |
| `Delete` / `Backspace` / `X` | 删除选中标注 |
| `Ctrl+Z` / `Z` | 撤销上一步 |
| `Ctrl+S` / `S` | 保存当前帧（人工保存即视为已复核） |
| `←` / `→` | 上一帧 / 下一帧 |

### 标签快速选择（右键弹窗内）

| 按键 | 行为 |
|------|------|
| `鼠标右键`（移动模式，点标签） | 弹出标签列表，输入框**自动聚焦** |
| `数字`（如 `0`、`12`） | 按序号前缀实时过滤列表 |
| `Enter` | 输入完整序号后确认选中并关闭列表 |
| `Esc`（输入框内） | 关闭标签列表 |

> 标签序号从 **0** 开始，与右栏"任务编辑 → 标签集"中的序号一致。
> 高频节奏：**右键 → 数字 → Enter**，三步完成换标签。

## 🚀 部署运行

```bash
pip install -r requirements.txt
python app.py --port 8880
```

- 数据目录（数据库、抽帧、标签、上传）位于 `data/`，首次运行自动初始化；
- 原始视频与帧图通过路径映射支持跨机（VM/Windows）共享存储；
- Windows 可用 `schtasks` 注册开机自启（参考仓库外部署文档）。

## 📁 目录结构

```
app.py            # Flask 入口与蓝图注册
auth.py           # 认证（token + 密码哈希）
db.py             # SQLite 初始化与访问
api/              # REST API 蓝图（auth/users/videos/datasets/stats/anno_tasks/gallery）
ui/               # 前端（每页独立 html + js，无构建依赖）
data/             # 运行时数据（不入库）
weights/          # SAM2 等模型权重（不入库）
```

## 🔒 安全说明

- 密码仅存哈希（werkzeug），接口走 Bearer Token；
- `data/`、`weights/`、日志、`__pycache__` 均在 `.gitignore` 中，不入仓库。
