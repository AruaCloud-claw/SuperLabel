# SuperLabel — 视频抽帧标注平台

基于 Flask + SQLite 的轻量级视频帧标注平台，支持多人协作的"抽帧 → 预标注 → 人工复核 → 导出"全流程。

## 功能

- **任务管理**：多视频上传、抽帧（可配置帧率/最大帧数）、任务图像池
- **标注编辑器**：矩形（两点绘制）/ 多边形标注、8向缩放、框移动、标签颜色分类、Ctrl+Z 撤销、空格/Ctrl 临时移动模式
- **预标注**：SAM2 / VLM 批量预标注接口，人工复核即确认
- **批量操作**：勾选批量删帧、全选、范围选择、一键定位未复核帧
- **权限**：admin / lead / annotator 三角色
- **发布导出**：一键发布数据集（YOLO 格式），目录浏览器导出

## 运行

```bash
pip install -r requirements.txt
python app.py --port 8880
```

数据目录（数据库、抽帧、标签）位于 `data/`，首次运行自动初始化，默认需注册管理员。

## 目录结构

```
app.py            # 入口（Flask 应用）
auth.py           # 认证（token + 密码哈希）
db.py             # SQLite 初始化与访问
api/              # REST API 蓝图（任务/数据集/视频/用户/图库等）
ui/               # 前端（每页独立 html + js，无构建依赖）
weights/          # SAM2 等模型权重（不入库）
```

> 内部研发工具，遵循团队编码规范；数据与权重不入库。
